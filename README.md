This repository will hold the machine-checked proofs of the exact finite results in
*The Permutation Coboundary Constant of the Complete Complex Is k/3 for 4 ≤ k ≤ 8*, built in Lean 4 with Mathlib (and Physlib where it helps), checked on every push the
same way as the other proof repositories on [my profile](https://github.com/dicipler-pixel).
